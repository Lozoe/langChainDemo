ALS.py 代码解析

基于交替最小二乘（ALS）的矩阵分解实现，用于 MovieLens 评分预测与 Top-N 推荐。

1. 整体架构

项目由三部分组成：自定义 Matrix 类、ALS 推荐模型、以及数据加载与主流程。

flowchart LR subgraph 输入 A[ratings_small.csv] end subgraph 核心 B[Matrix 类] C[ALS 类] end subgraph 输出 D[Top-N 推荐] E[RMSE] end A --> C B --> C C --> D C --> E

2. Matrix 类结构

手写矩阵类，支持行/列提取、转置、求逆（高斯消元）、矩阵乘法等，为 ALS 提供稠密矩阵运算。

classDiagram class Matrix { +list~list~ data +tuple shape +row(row_no) Matrix +col(col_no) Matrix +is_square bool +transpose Matrix +eye Matrix +inverse Matrix +mat_mul(B) Matrix +mean() Matrix +scala_mul(scala) Matrix -_eye(n) list -_gaussian_elimination(aug_matrix) list -_inverse(data) list -_row_mul(row_A, row_B) float -_mat_mul(row_A, B) list -_mean(data) list }

主要方法说明

  • row/col：按索引取行/列，返回 1 行或 1 列的 Matrix。
  • transpose：转置矩阵（zip 实现）。
  • inverse：方阵求逆，内部用增广矩阵 + 高斯消元化为单位阵，取右半部分即为逆矩阵。
  • mat_mul(B)：矩阵乘法 A×B，用 _mat_mul 对 A 的每一行与 B 的列做点积。

3. ALS 类结构

交替最小二乘：将评分矩阵 R 近似为 U×V，固定 U 更新 V，再固定 V 更新 U，迭代至收敛。

classDiagram class ALS { +user_ids tuple +item_ids tuple +user_ids_dict dict +item_ids_dict dict +user_matrix Matrix +item_matrix Matrix +user_items dict +shape tuple +rmse float +fit(X, k, max_iter) +predict(user_ids, n_items) list -_process_data(X) ratings, ratings_T -_users_mul_ratings(users, ratings_T) Matrix -_items_mul_ratings(items, ratings) Matrix -_gen_random_matrix(n_rows, n_colums) Matrix -_get_rmse(ratings) float -_predict(user_id, n_items) list }

4. 数据流程：从原始数据到稀疏结构

_process_data(X) 把 (user_id, item_id, rating) 列表转为两个稀疏视图，并建立 id→下标 映射。

flowchart TB subgraph 输入 X X1["[(user_id, item_id, rating), ...]"] end subgraph _process_data A[提取 user_ids / item_ids] B[枚举建 user_ids_dict, item_ids_dict] C[构建 ratings: user_id -> item_id -> rating] D[构建 ratings_T: item_id -> user_id -> rating] end subgraph 输出 E["ratings: {user: {item: rating}}"] F["ratings_T: {item: {user: rating}}"] end X1 --> A A --> B B --> C B --> D C --> E D --> F

5. ALS 训练流程（fit）

每次迭代：奇数步用当前 item 矩阵更新 user 矩阵；偶数步用当前 user 矩阵更新 item 矩阵。更新公式来自最小二乘闭式解。

flowchart TB Start[_process_data 得到 ratings, ratings_T] --> Init[随机初始化 user_matrix: k×m] Init --> Iter{迭代 i = 0 .. max_iter-1} Iter -->|i 为偶数| FixUser[固定 user_matrix] FixUser --> UpdateItem["更新 item_matrix: 闭式解 U^T U inv"] UpdateItem --> RMSE1[计算 RMSE] RMSE1 --> Iter Iter -->|i 为奇数| FixItem[固定 item_matrix] FixItem --> UpdateUser["更新 user_matrix: 闭式解 V^T V inv"] UpdateUser --> RMSE2[计算 RMSE] RMSE2 --> Iter Iter --> End[保存最终 rmse]

其中 U = user_matrix（k×m），V = item_matrix（k×n）。_users_mul_ratings / _items_mul_ratings 实现稠密矩阵与稀疏评分的乘法，避免构造完整大矩阵。

6. Top-N 推荐流程（predict）

对每个用户，用其 user 向量与所有 item 向量相乘得到预测分，过滤已评分的物品后按分数取 Top-N。

flowchart LR subgraph _predict A[user_id] --> B[取 user 列向量] B --> C[user_row × item_matrix] C --> D[得到每个 item 的预测分] D --> E[过滤已评分 item] E --> F[按分数排序取 Top-N] end F --> G["(item_id, score) 列表"]

8. 关键公式与变量

符号含义
R评分矩阵（稀疏），m 用户 × n 物品
k隐因子维度（矩阵分解的秩）
U (user_matrix)用户矩阵 k×m，每列对应用户向量
V (item_matrix)物品矩阵 k×n，每列对应物品向量
R ≈ U^T × V低秩近似，预测分 = 用户向量 · 物品向量
固定 V 求 UU = (V V^T)^(-1) V R^T（按列的最小二乘）
固定 U 求 VV = (U U^T)^(-1) U R（代码中通过 ratings_T 实现）
